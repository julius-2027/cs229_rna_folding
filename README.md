# cs229_rna_folding

kinpfn_testing_set is taken from https://github.com/automl/KinPFN/tree/main/kinpfn_testing_set, the github for the KinPFN paper by Scheuer et. al.

We performed our own analysis of the folding time distributions for the 635 RNA sequences from kinpfn_testings_set:
* Print-out of all 635 folding time histograms
* Plots of median folding time vs RNA sequence length, GC content, and MFE
